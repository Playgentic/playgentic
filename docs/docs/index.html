Getting started

playgentic is a zero-dependency CLI that scaffolds a Playwright-BDD suite pre-wired for a Claude Code agent pipeline that writes and heals your tests. This page gets you from nothing to a running suite plus a first agent-generated scenario.

Requirements Node >= 18 and npm. For the agent pipeline: Claude Code with the playwright-test MCP server (already wired in the scaffold's .mcp.json).

1 · Scaffold a suite

Create a new suite in its own folder:

$ npx playgentic init my-suite
$ cd my-suite

Adding tests to an existing project instead? Run it in place — it merges into your package.json (adds scripts + devDeps, never clobbers yours):

$ cd my-existing-app
$ npx playgentic init .

2 · Point it at your app

Copy the env template and set TARGET_URL to the app under test. This becomes Playwright's baseURL, so steps navigate with relative paths.

$ cp .env.example .env
# .env
TARGET_URL = https://your-app.example.com
# Optional auth creds — read via the world fixture, never hardcoded in features
# STANDARD_USER = 
# STANDARD_PASS =

Credentials belong in .env (or CI secrets), not in .feature files. See Working off the template → Credentials.

3 · Install browsers & run

Install the Playwright browsers, generate the step wiki, and run the example scenario.

$ npx playwright install
$ npm run wiki   # generate the step catalogue under docs/
$ npm test       # run the example scenario

See Playwright → Browsers for browser/OS specifics.

4 · Let the agents write coverage

In Claude Code, run the pipeline skill. The orchestrator plans cases, scaffolds an isolated session, dispatches the bdd-explorer to drive the live app, has the bdd-auditor review, and presents the result for your approval before anything is promoted into tests/.

# in Claude Code, from the suite root
> /bdd-pipeline --gen    # add coverage
> /bdd-pipeline --heal   # repair a broken/flaky test

Read the full design in Architecture → Agent pipeline.

5 · Keep agents up to date

Agent definitions (.claude/skills, .claude/agents) are managed by playgentic. When a new version ships, pull the changes into any scaffolded project:

$ npx playgentic sync         # update managed agent defs
$ npx playgentic sync --dry   # preview changes only

sync overwrites the managed skills/agents but never touches .claude/rules/code-styles.md (your standards) or any skill/agent you added. Details in Architecture → the sync model.
