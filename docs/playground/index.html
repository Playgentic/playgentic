    Automate it yourself

    Scaffold a suite, set TARGET_URL to this page, and run /bdd-pipeline --gen. The agents explore each widget above and write Playwright-BDD coverage against these exact selectors.

    Getting started → Working off the template → 
    $ npx playgentic init pg-demo && cd pg-demo
$ echo "TARGET_URL=https://blaisemoses01.github.io/playgentic/playground/" > .env
$ npx playwright install
> /bdd-pipeline --gen   # in Claude Code
